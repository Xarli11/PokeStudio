# ADR-0006: GitHub for repository, CI and early community

- Status: Accepted
- Date: 2026-09-08

## Context

PokeStudio intends to be source-visible/community-driven and needs pull requests, CI, issues, discussions and contributor workflows.

## Decision

Use GitHub as the primary code hosting and early community platform.

## Consequences

- GitHub Actions for CI,
- Issues/Discussions for community input,
- contributor/license process must be ready before actively soliciting broad PRs.
